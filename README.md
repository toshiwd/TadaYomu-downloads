# TadaYomu downloads

Signed Android APKs, in-app update metadata and licensed optional reader fonts.
The application source and development history are kept in a separate private repository.

Use Releases to download an APK. For the first distribution migration, install v1.3.82
over the existing app without uninstalling. Later updates use Settings in TadaYomu.
The Android installer still asks for confirmation.

Only README is stored in this repository's Git history. Release assets contain APKs,
version.json and Noto Serif JP fonts with their original SIL Open Font License 1.1.
APK compiled code and resources can be extracted.

Fonts are in the `fonts-noto-serif-jp-1` release. Copyright 2012 Google Inc.
See the bundled NotoSerifJP-OFL.txt for copyright and license conditions.
